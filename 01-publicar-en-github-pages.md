# 🛠️ Proceso de creación de mi página web

En este apartado explico el proceso que seguí para crear y publicar mi página web personal utilizando GitHub Pages y Just the Docs.

## 1. 💡 Planeación

Primero definí el objetivo de mi página web. La idea principal fue crear un portafolio personal donde pudiera presentar información sobre mí, mis habilidades, proyectos y experiencia académica.

También organicé las diferentes secciones que tendría la página para facilitar la navegación.

## 2. 🖥️ Creación del repositorio

El primer paso técnico fue crear un repositorio en GitHub para almacenar todos los archivos de mi página web.

GitHub permite guardar las diferentes versiones del proyecto y facilita la publicación de la página mediante GitHub Pages.

## 3. 🎨 Diseño de la página

Después seleccioné y configuré el tema **Just the Docs** para darle una estructura organizada a mi sitio.

Este tema permite crear una barra de navegación y diferentes apartados de manera sencilla.

## 4. 💻 Desarrollo

Para desarrollar la página utilicé diferentes tecnologías:

- **HTML:** estructura del contenido.
- **CSS:** diseño y apariencia.
- **Markdown:** creación de las diferentes páginas.
- **Jekyll:** generación del sitio web.
- **GitHub Pages:** publicación del sitio en Internet.

## 5. 📁 Organización de los archivos

Organicé el proyecto mediante diferentes archivos Markdown.

La estructura básica quedó de la siguiente manera:

```text
portafolio-just-the-docs/
│
├── _config.yml
├── index.md
├── proceso-creacion.md
├── proyectos.md
├── habilidades.md
│
└── assets/
